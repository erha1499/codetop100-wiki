## 思路

- **排序 + 固定一个数 + 两数之和（左右双指针）**。
- 枚举第一个数 `nums[i]`，在 `[i+1, n-1]` 里用 `lo / hi` 夹：和小了 `lo++`，大了 `hi--`，等于 0 记录答案。
- 剪枝：排序后 `nums[i] > 0` 直接 `break`。
- 同套路：最接近的三数之和、四数之和。

## 易错点

- 去重有两处：① 第一个数 `i > 0 && nums[i] == nums[i-1]` 跳过；② 找到答案后 `lo`、`hi` 各自跳过相同值。
- 去重之后**还要再 `lo++ / hi--`**，否则死循环。

## 代码

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n, res = len(nums), []
        for i in range(n):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:      # 第一个数去重
                continue
            lo, hi = i + 1, n - 1
            while lo < hi:
                s = nums[i] + nums[lo] + nums[hi]
                if s < 0:
                    lo += 1
                elif s > 0:
                    hi -= 1
                else:
                    res.append([nums[i], nums[lo], nums[hi]])
                    while lo < hi and nums[lo] == nums[lo + 1]:   # 左右去重
                        lo += 1
                    while lo < hi and nums[hi] == nums[hi - 1]:
                        hi -= 1
                    lo += 1
                    hi -= 1
        return res
```

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;       // 第一个数去重
            int lo = i + 1, hi = n - 1;
            while (lo < hi) {
                int sum = nums[i] + nums[lo] + nums[hi];
                if (sum < 0) {
                    lo++;
                } else if (sum > 0) {
                    hi--;
                } else {
                    res.add(List.of(nums[i], nums[lo], nums[hi]));
                    while (lo < hi && nums[lo] == nums[lo + 1]) lo++;   // 左右去重
                    while (lo < hi && nums[hi] == nums[hi - 1]) hi--;
                    lo++;
                    hi--;
                }
            }
        }
        return res;
    }
}
```

**复杂度**：时间 O(n²)，空间 O(log n)（排序栈，不计答案）。
